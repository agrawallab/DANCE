# Continuous Optogenetic Stimulation Script

## Description

This script is for continuous optogenetic stimulation using Arduino based LED control.

## Features

- Provides continuous LED stimulation while recording behavior.

## Usage

1. Connect input pin on 8 or 13 and ground of Arduino board from the LED strips.
2. Connect Arduino to PC system and preload the code, crosscheck the LED blink by pressing reset button on Arduino.
3. Disconnect the Arduino cable which acts as power supply from the PC setup, until you start the experiment.
4. Once ready to start recording, reconnect the Arduino cable and press record video simultaneously.
